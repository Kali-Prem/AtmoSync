## 1. Overview & Data Contract Purpose

This document establishes the canonical JSON data contract exchanged across the five core tiers of the platform:

```
[Scientific Engine / CAMS]
             ↓
[Physics-Informed ML Ensemble]
             ↓
[Database & TimescaleDB Hypertables]
             ↓
[FastAPI REST / WebSocket Gateway]
             ↓
[Next.js Interactive Command Center]
```

Every forecast generated by the backend or consumed by the web client **must strictly conform** to this schema.

## 3. Phase 5 Operational Forecast Data Contract Extension

As mandated by Phase 5, multi-horizon forecasts produced by the hybrid engine and served via REST API (`/api/v1/forecasts/stations/{code}`) must provide the following normalized contract fields per step:

| Contract Field | Type | Description | Phase 5 Source |
|---|---|---|---|
| `forecast_id` | `string` | Unique forecast batch identifier | Auto-generated UUID / Cycle |
| `station_id` / `grid_id` | `string` | Station identifier or 0.1° grid cell | CPCB Station Code |
| `forecast_issue_time` | `ISO-8601` | Cycle timestamp ($t_0$) | Ingestion cycle timestamp |
| `target_time` | `ISO-8601` | Forecast target timestamp ($t_0 + h$) | Step valid time |
| `horizon_hours` | `integer` | Lead time in hours (1, 6, 12, 24, 48, 72) | Forecast lead horizon |
| `predicted_pm25` | `float` | Predicted PM2.5 concentration ($\mu g/m^3$) | LightGBM / Baseline Model |
| `temperature_2m` | `float` | Predicted 2 m air temperature (°C) | Open-Meteo ERA5 / NWP |
| `relative_humidity` | `float` | Predicted relative humidity (%) | Open-Meteo ERA5 / NWP |
| `wind_speed` | `float` | 10 m horizontal wind speed (m/s) | Open-Meteo ERA5 / NWP |
| `wind_direction` | `float` | 10 m meteorological wind direction (°) | Open-Meteo ERA5 / NWP |
| `pbl_height` | `float` | Boundary layer height (m AGL) | Bulk Richardson / ECMWF |
| `inversion_present` | `boolean` | Flag indicating active thermal inversion | Multi-level Profile Gradient |
| `inversion_strength` | `float` | Low-level lapse rate $\Gamma_{\text{low}}$ (°C/100m) | Inversion Diagnostics |
| `fire_event_count` | `integer` | Active regional fire clusters detected | NASA FIRMS VIIRS 375m |
| `plume_influence_score`| `float` | Normalized plume risk index (0.0 - 100.0) | Forward Puff Transport |
| `plume_confidence` | `string` | Risk score certainty (`HIGH`, `NOMINAL`, `LOW`)| Transport Engine |
| `model_name` | `string` | Forecasting model family | `LightGBM-Lagged-GBDT` |
| `model_version` | `string` | Semantic model version | `v1.2.0-phase5` |
| `data_quality` | `string` | Forecast pipeline QC status | `VALID`, `DEGRADED` |
| `uncertainty` | `object` | P10 - P90 prediction interval | Conformal Quantile Bounds |
